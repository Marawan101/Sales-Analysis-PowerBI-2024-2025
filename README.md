# 📊 Sales Analysis Dashboard | 2024–2025

## 📌 Project Overview
An interactive Sales Analysis Dashboard developed using Microsoft Power BI to analyze and evaluate sales performance across 2024 and 2025.

The project transforms raw sales data into meaningful insights through interactive visualizations and business performance indicators.

## 🎯 Project Objectives
- Analyze overall sales performance.
- Compare sales results between 2024 and 2025.
- Track key performance indicators (KPIs).
- Identify sales trends and patterns.
- Support data-driven business decisions.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📈 Key Performance Indicators
- Gross Sales
- Net Sales
- Sales Returns
- Number of Orders
- Total Quantity Sold
- Monthly Sales Performance

## 📅 Analysis Period
2024 – 2025
